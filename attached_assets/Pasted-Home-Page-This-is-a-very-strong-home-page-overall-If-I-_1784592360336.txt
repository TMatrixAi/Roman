Here’s exactly what I’d tell Replit:

⸻

Force Signal UX Redesign (Required)

The current Force Signal page is confusing because it duplicates the Build Matchup page. Users should not feel like they’re using a different prediction engine.

1. Keep the same Build Matchup page

Do not create a separate Force Signal prediction workflow.

Force Signal uses the same engine and same player selection as Build Matchup.

⸻

2. Repurpose the FS button

Instead of opening another prediction page, the FS button should simply toggle Force Signal Mode ON/OFF globally.

Behavior:

	•	⚡ Gray = OFF
	•	⚡ Gold = ON

When ON, every prediction runs in Force Signal mode until turned off.

No page change.

No duplicate UI.

⸻

3. Show a small banner

When Force Signal is enabled, show a compact banner at the top of Build Matchup:

⚡ Force Signal Enabled

Close matches will receive a forced directional pick instead of “No Signal.”

Results are tracked separately and excluded from normal accuracy metrics.

This should replace the giant warning box.

⸻

4. Add a Help page

If users tap the ⚡ icon again or tap an info icon, open the current explanation page as an information screen only.

Move all of the educational content there.

⸻

5. Track separately

Every Force Signal prediction must automatically receive:

	•	Force Signal badge
	•	Separate ledger
	•	Separate accuracy
	•	Excluded from production accuracy

⸻

6. Prediction results

When Force Signal is ON:

Instead of

Recommendation: No Signal

show

⚡ Forced Pick

and display:

	•	Forced Winner
	•	Raw Probability
	•	Reason it was forced
	•	Close Match Warning

⸻

7. Never duplicate pages

There should only be one place where users:

	•	Search players
	•	Paste matches
	•	Upload screenshots
	•	Run bulk predictions

Force Signal changes only the output, never the workflow.

⸻
