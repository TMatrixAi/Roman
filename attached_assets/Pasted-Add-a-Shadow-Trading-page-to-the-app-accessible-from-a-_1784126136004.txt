**Page purpose**
This page displays Shadow Replay evidence only — the fast, leakage-safe simulated results from replaying held-out historical dates through the live prediction engine. It must never blend with or be mistaken for real live paper-trading results.

**Required sections on the page**

1. **Header disclosure banner** — Always visible at the top: "Shadow Replay: Simulated evidence from historical replay, not live-graded results. See Ledger for real live paper-trading performance." Clear text, not obnoxious — subtle background tint, small icon.

2. **Summary KPI row** — Total shadow-replayed predictions (sample size), overall accuracy, Brier score/calibration score, date range covered, last updated timestamp.

3. **Batch selector** — If multiple shadow-replay batches exist, let the user pick one or view all combined. Show batch ID, date range, and run date per batch.

4. **Calibration breakdown** — Accuracy by probability band (50-60%, 60-70%, etc.).

5. **Tier performance breakdown** — Win rate and sample size per recommendation tier (Strong Recommendation, Elite, Moderate Lean, No Strong Signal, etc.), within shadow-replay data only.

6. **Match-level results table** — Paginated: date, players, tour, predicted winner, predicted probability, tier, actual result, correct/incorrect. Sortable and filterable by tour, tier, date range, correct/incorrect.

7. **Comparison strip** — Shadow Replay accuracy vs. real Live Paper Trading accuracy vs. Backtest/historical_test accuracy, each clearly labeled. Link out to the Ledger page for live paper-trading detail.
