Improve the Tennis Prediction App

### Prediction Engine
- Fix the prediction weighting so the final winner always reflects the strongest underlying evidence.
- If Surface Elo, Simulation Win Probability, Recent Form, Expected Games, Head-to-Head, Surface Record, Serve/Return Performance, and other high-confidence metrics all favor the opposite player, the engine must not override them without a strong statistical reason.
- Add a "Model Conflict" warning whenever the final prediction disagrees with the majority of the highest-weight metrics.
- Recalibrate feature weights so the predicted winner remains consistent with the underlying analytics.
- Display a concise explanation showing which metrics determined the final prediction.

### Self-Learning Engine
- Analyze every historical prediction (wins and losses).
- Identify which metrics consistently appear in winning predictions and which consistently appear in losing predictions.
- Automatically increase the weight of metrics that correlate with wins.
- Automatically reduce or remove metrics that repeatedly correlate with losses or introduce noise.
- Continuously retrain and recalibrate the model as new match results are recorded.
- Prioritize predictive accuracy over equal weighting.
- Generate an analytics report showing which features were strengthened, weakened, or removed and why.

### Automatic Win/Loss Tracking
- Continuously check completed matches using reliable data sources.
- Automatically mark every prediction as Win or Loss without manual input.
- Update prediction history, learning data, and statistics immediately after official results become available.

### Automatic Terrain Detection
- When a user selects a match from Today's Fixtures and clicks Predict or Predict Now, automatically detect the correct playing surface (Hard, Clay, Grass, Carpet, Indoor Hard, etc.).
- Preselect the correct terrain before loading the prediction page.
- Allow manual overrides if needed.

### Main Page Improvements
- Add a new blue button beside Predict called "Predict Now."
- Predict Now should skip the Match Setup page and go directly to the Prediction page while automatically populating player names, tournament, date, time, and terrain.
- Rename the existing Predict button to "Custom Match" for manual editing.

### Fixture Organization
- Keep Today's Fixtures sorted by:
  1. Date
  2. Start Time
  3. Tournament

### Tournament Filter
- Add a dropdown beside View Ledger containing:
  - All Matches
  - ITF
  - ATP Tournaments (alphabetically, then by date and start time)
  - WTA Tournaments (alphabetically, then by date and start time)

### Ledger Improvements
- Add a Delete Match button inside View Ledger.
- Allow deleting individual or multiple matches.
- Update learning data appropriately after deletion.

### Accuracy Improvement
- Review every prediction component and determine what consistently contributes to wins versus losses.
- Enhance metrics that improve prediction accuracy.
- Reduce or remove metrics that consistently reduce prediction accuracy.
- Never fabricate missing data. Prefer verified provider data whenever available.
- Ensure every prediction is driven by the highest-quality evidence available while remaining transparent about uncertainty.

### Refresh Buttons

Main Page
- Add a "Refresh Matches" button on Today's Fixtures.
- When pressed:
  - Fetch the latest fixtures from all connected APIs.
  - Update match times, player names, tournaments, court surfaces, and match status.
  - Add newly scheduled matches.
  - Remove cancelled or completed matches.
  - Refresh without requiring a page reload.

View Ledger
- Add a "Refresh Prediction Outcomes" button.
- When pressed:
  - Recheck every stored prediction against official match results.
  - Automatically update pending predictions to Win or Loss.
  - Refresh prediction statistics, win percentage, and self-learning data.
  - Skip already verified matches unless newer official data is available.
  - Display the last successful refresh time.

### Automatic Background Refresh
- Automatically refresh Today's Fixtures every 5–10 minutes while the app is open.
- Automatically check completed match results every 15–30 minutes.
- Include loading indicators and graceful API error handling.
- Never overwrite verified results with incomplete or unofficial data.

Goal: Build a continuously self-improving tennis prediction engine that automatically learns from results, keeps fixtures and prediction outcomes updated, removes weak predictive signals, strengthens winning signals, minimizes contradictory predictions, and delivers the most accurate predictions possible using verified data.
