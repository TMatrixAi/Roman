Fix the screenshot match-import feature so the app itself reliably extracts every tennis match shown in an uploaded screenshot.

Requirements:

1. Accept screenshots containing one or multiple match cards.
2. Detect each match card separately before reading its text.
3. Extract:

   - Start time
   - Time zone
   - Player 1
   - Player 2
   - Any visible odds

10. Allow the user to edit any incorrectly extracted name, event, date, or time.
11. Add a “Retry extraction” button.

- Merge both passes and remove duplicates.
- Validate that each match has exactly two likely player names.
- Use surrounding layout and text position, not OCR text alone, to associate players, times, odds, and tournament names.
