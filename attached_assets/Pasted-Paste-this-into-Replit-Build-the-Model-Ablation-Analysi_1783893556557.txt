Ablation method

First run the baseline evaluation with every model active.

Then replay the same frozen historical matches multiple times, removing one model source per run.

For each removed model:

* Remove only that model’s vote.
* Keep every other input and rule unchanged.
* Re-normalize the remaining weights using the engine’s existing production method.
* Use only frozen pre-match snapshots.
* Do not fetch current player data.
* Do not use post-match information.
* Do not retrain models during the analysis.
* Do not alter the historical records.

The result should answer:

Does accuracy improve or decline when this model is removed?

Main results

Display a mobile-friendly results table or stacked cards with:

* Model removed
* Baseline accuracy
* Accuracy without the model
* Accuracy change
* Matches analyzed
* Recommendation

Example:

Fatigue

Baseline accuracy: 67.4%
Accuracy without Fatigue: 69.1%
Change: +1.7 percentage points
Recommendation: Candidate for lower weight

Interpret the results correctly:

* Accuracy drops when removed = model is helping.
* Accuracy stays nearly unchanged = model is neutral.
* Accuracy improves when removed = model may be hurting.

Use these recommendation labels:

* Keep
* Review
* Candidate for lower weight
* Potential removal candidate
* Insufficient sample
